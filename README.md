# Finance & Accounting Analytics with Python

A practical portfolio project demonstrating how Python can support finance, accounting, and internal audit analysis using synthetic transaction data.

## Business objectives

- Clean and validate finance transaction data
- Analyse monthly revenue and expenses
- Compare budget with actual performance
- Identify unusual and potentially duplicate transactions
- Analyse vendor and expense concentration
- Calculate management KPIs
- Produce concise management insights

## Tools

- Python 3
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- openpyxl

## Data privacy

All data in this repository is synthetic and created solely for demonstration. No confidential company, customer, supplier, employee, or financial information is used.

## Analytical approach

The project follows a practical workflow:

1. Load and validate transactions
2. Standardise dates, categories, and numeric fields
3. Calculate financial KPIs
4. Perform budget-versus-actual analysis
5. Test for transaction exceptions
6. Analyse vendor and expense concentration
7. Summarise findings for management review

## Planned outputs

The notebook will generate summary tables, exception lists, and charts suitable for a management review pack.
