# Management Report Output

Run:

```bash
python src/report_generator.py
```

The script creates `finance_management_report.xlsx` in this folder with:

- Executive Summary
- Monthly Analysis
- Category Analysis
- Vendor Analysis
- Duplicate Invoices
- Budget Exceptions
- High Value Transactions
- Full Transactions

The workbook is generated from the synthetic dataset in `data/sample_transactions.csv`.
